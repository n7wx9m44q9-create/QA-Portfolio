# Project Scope

## Product

**The Battle for Wesnoth**

## Testing Type

Localization QA / Localization Testing

## Localization

**Source language:** English  
**Target language:** Spanish

## Functional Area

**Tutorial Campaign**

The project is intentionally limited to the Tutorial Campaign to maintain a manageable and reproducible testing scope.

## Objective

Verify that the Spanish localization of the Tutorial Campaign:

- Correctly communicates the meaning of the English source text.
- Uses appropriate Spanish grammar and spelling.
- Maintains consistent terminology.
- Uses an appropriate and consistent linguistic register.
- Preserves the intended context of instructions and dialogues.
- Does not introduce functional ambiguity through localization.
- Is correctly displayed within the game's user interface.

## In Scope

### Content

- Tutorial dialogues
- Narrative text
- Tutorial instructions
- Objectives
- Messages
- Relevant system text
- Unit names
- Character names
- Faction names
- Location names
- Gameplay terminology used within the Tutorial

### UI

- Buttons
- Dialog windows
- Labels
- Messages
- Menus directly related to the Tutorial
- Text containers
- Text formatting and line breaks

### Localization Quality

- Translation accuracy
- Grammar
- Spelling
- Punctuation
- Gender and number agreement
- Terminology consistency
- Character and place name consistency
- Player address and linguistic register
- Contextual accuracy
- UI localization issues

## Out of Scope

The following areas are intentionally excluded from the main testing scope:

- Random gameplay tips displayed at application startup
- Other campaigns
- Multiplayer
- Map editor
- User-made content
- Add-ons
- Other platforms
- Other target languages

Findings discovered outside the defined scope may be recorded as exploratory observations but will not form part of the main test results.

## Entry Criteria

Testing can begin when:

- [ ] The game version has been recorded.
- [ ] The testing platform has been recorded.
- [ ] English and Spanish languages are available.
- [ ] The Tutorial Campaign can be accessed.
- [ ] The documentation structure has been prepared.

## Exit Criteria

Testing can be considered complete when:

- [ ] The defined Tutorial scope has been explored.
- [ ] Relevant localization checks have been performed.
- [ ] Identified defects have been reproduced where possible.
- [ ] Valid defects have been documented.
- [ ] Test evidence has been collected.
- [ ] Known limitations and out-of-scope observations have been documented.

# [Spanish] Ambiguous defeat message uses inconsistent player address

## Environment

- Game: The Battle for Wesnoth
- Campaign: Tutorial Campaign
- Language: Spanish
- Scenario: Tutorial — first scenario
- Character: Lisar
- Platform: macOS
- Version: [add game version]

## Description

The defeat message in the Spanish localization uses an ambiguous pronoun and is inconsistent with the informal second-person address used throughout the tutorial.

The game displays:

> "¡Le han derrotado!"

The Spanish tutorial consistently addresses the player using the informal second-person form (`tú`), for example:

- "te enseña"
- "te gustaría"
- "Estás ocupando"
- "puedes"
- "Haz clic"

The use of `le` in the defeat message can be interpreted either as a third-person reference ("him/her") or as formal second-person address ("usted"), making the intended recipient of the message ambiguous.

## Steps to Reproduce

1. Launch The Battle for Wesnoth.
2. Set the game language to Spanish.
3. Start the Tutorial Campaign.
4. Select Lisar as the playable character.
5. Progress through the tutorial until a defeat condition is triggered.
6. Observe the defeat message.

## Actual Result

The game displays:

> "¡Le han derrotado!"

## Expected Result

The message should clearly address the player using the same informal second-person form used throughout the tutorial.

For example:

> "¡Has perdido!"

Another possible formulation would be:

> "¡Has sido derrotado!"

However, the first option also avoids introducing gender agreement issues.

## English Source

The corresponding English message is:

> "You have been defeated!"

## Impact

The current Spanish localization makes the intended recipient of the message ambiguous and introduces an inconsistent form of address compared with the rest of the tutorial.

This may reduce clarity for Spanish-speaking players, particularly because the message appears at an important gameplay state transition.

# L10N-003 — Main menu tip mixes informal and formal player address

## ID
L10N-003

## Title
[Spanish] Main menu tip mixes informal and formal player address

## Area
Main Menu → Tips / Advice

## Environment
- Game: The Battle for Wesnoth
- Version: 1.18.8
- Language: Spanish
- Platform: macOS
- Localization: English → Spanish

## Severity
Minor

## Priority
Medium

## Preconditions
- The game is configured in Spanish.
- The main menu is displayed.
- The tips/advice panel is available.

## Steps to Reproduce
1. Launch The Battle for Wesnoth.
2. Set the game language to Spanish.
3. Open the main menu.
4. Use the `Siguiente` / `Anterior` buttons in the tips panel to browse the available messages.
5. Locate the tip about leveling up units with an experienced unit.

## Actual Result
The same message mixes informal and formal forms of address:

> «Para hacer subir de nivel a tus unidades rápidamente, agrúpelos con un veterano y use al veterano para debilitar a un enemigo común lo suficiente como para que un compañero novato pueda dar el golpe de gracia.»

The message begins with the informal possessive **«tus»**, but then switches to formal imperative forms:

- **tus** unidades → informal (`tú`)
- **agrúpelos** → formal (`usted`)
- **use** → formal (`usted`)

## Expected Result
The message should maintain a consistent form of address throughout the same text.

For example:

> «Para hacer subir de nivel a tus unidades rápidamente, agrúpalas con un veterano y usa al veterano para debilitar a un enemigo común lo suficiente como para que un compañero novato pueda dar el golpe de gracia.»

## Impact
The change from informal to formal address within a single message creates a noticeable localization inconsistency and can make the Spanish text appear incorrectly edited or assembled from different translation variants.

The issue does not prevent the player from understanding the gameplay advice, but it affects localization quality and consistency.

Screenshot:

## Validation
All available main-menu tips were reviewed using the `Anterior` and `Siguiente` buttons.

The mixed `tú` / `usted` treatment was observed only in this message.

Other tips use either informal or formal address consistently within their individual messages. Differences in register between separate tips were therefore not reported as defects.
